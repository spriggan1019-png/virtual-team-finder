# Round3. 쌈뽕 깔롱한 것
가상 팀원 모집 웹사이트

## 프로젝트 소개
팀원들과 GitHub, Figma, Notion을 활용해 협업하며 가상의 팀원을 모집하는 웹사이트를 기획하고 제작
GitHub로 코드를 공유하고 관리하고, Figma로 디자인을 공유하며, Notion으로 기획 자료와 진행 내용을 정리
각 도구를 활용해 팀원들과 의견을 나누고 작업을 구체화

## 역할 
리더 - Modernia 
프로젝트의 방향을 설정하고 여러 곳을 담당하며 팀을 이끌어갔다.
웹사이트 완성본 제작, 디자인, figma, notion을 이용한 기획

기술 담당 - 나
웹페이지 코딩과 기능 구현을 담당했다. 
웹사이트 Prototype제작, 웹사이트 완성본 제작, 모집 포스터 디자인&제작, figma, notion을 이용한 기획 참여


## 협업 방식
GitHub: 웹사이트 코드 공유 및 변경 사항 관리
Figma: 디자인 작업 공유 및 의견 교환
Notion: 기획 자료와 프로젝트 진행 내용 정리

## 사용 기술 및 도구
웹 개발: HTML, CSS, JavaScript
데이터 전송 및 연동: Fetch API, JSON, Google Apps Script
-> 지원자의 정보를 입력받아 유효성을 검사하고, Google Apps Script로 전송

협업: GitHub, Figma, Notion
제작 도구: Visual Studio
